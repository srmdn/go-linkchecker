# AI Commit Cleanup

If a commit message contains banned AI attribution lines, remove them before
pushing.

Blocked lines include:

- `Co-authored-by: Claude ...`
- `Co-authored-by: ChatGPT ...`
- `Generated with Claude Code`
- `Generated by ...`

## Fix The Latest Commit

If only the most recent commit is affected:

```sh
git commit --amend
```

Delete the banned line from the editor, save, and exit.

## Fix Older Local Commits

If the bad line is in an older local commit:

```sh
git rebase -i <base-commit-before-bad-commits>
```

Mark the affected commits as `reword`, then remove the banned lines from each
commit message during the rebase.

## Fix Already-Pushed History

If the bad commit is already on the remote:

1. Rewrite the local history with `git commit --amend` or `git rebase -i`
2. Verify the cleaned commit messages
3. Push with:

```sh
git push --force-with-lease
```

Use force-push only when you understand the impact on collaborators.
